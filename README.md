# Nubnub (นับนับ)

แอปบันทึกรายรับ-รายจ่าย + ติดตามสต็อกของใช้ในบ้าน
ทำงานได้ทั้งมือถือและคอม ไม่มี backend ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ

## ไฟล์ในโปรเจกต์
- `index.html` — โครงหน้าเว็บ
- `style.css` — ดีไซน์ (โทนน้ำตาล-มัสตาร์ด มินิมอล)
- `script.js` — โลจิกทั้งหมด (บันทึก/ลบ/คำนวณ)

## วิธีอัพขึ้น GitHub ด้วย GitHub Desktop

1. **สร้าง repository ใหม่**
   เปิด GitHub Desktop → `File` → `New Repository...`
   ตั้งชื่อ `nubnub` → เลือกโฟลเดอร์ที่จะเก็บในเครื่อง → กด `Create Repository`

2. **ก็อปไฟล์เข้าโฟลเดอร์ repo**
   เอาไฟล์ `index.html`, `style.css`, `script.js` (จากในนี้) ไปวางในโฟลเดอร์ repo ที่เพิ่งสร้าง (โฟลเดอร์เดียวกับที่มี `.git` ซ่อนอยู่)

3. **Commit**
   กลับมาที่ GitHub Desktop จะเห็นไฟล์ขึ้นในช่อง Changes ทั้งหมด
   พิมพ์ข้อความ commit เช่น `first version of nubnub` → กด `Commit to main`

4. **Push ขึ้น GitHub**
   กดปุ่ม `Publish repository` (ถ้าเป็นครั้งแรก) หรือ `Push origin` (ครั้งถัดไป)
   ถ้าไม่อยากให้คนอื่นเห็นโค้ด ให้ติ๊ก "Keep this code private" ตอน publish ได้ (แต่ GitHub Pages แบบ private repo ต้องใช้แพลน Pro ถึงจะเปิด Pages ได้ ถ้าอยากใช้ Pages ฟรีต้องเป็น public repo)

5. **เปิดใช้งาน GitHub Pages**
   ไปที่หน้าเว็บ GitHub ของ repo (github.com/ชื่อคุณ/nubnub)
   → แท็บ `Settings` → เมนูซ้าย `Pages`
   → ในช่อง **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` → กด `Save`
   → รอสักครู่ (1-2 นาที) แล้วรีเฟรชหน้า จะมีลิงก์ขึ้นมาเช่น
   `https://ชื่อคุณ.github.io/nubnub/`

6. **ใช้งาน**
   เข้าลิงก์นั้นได้ทั้งจากมือถือ (iPhone เปิด Safari เข้าลิงก์ แล้วกด Share → "Add to Home Screen" จะได้เหมือนแอป) และจากคอม
   ⚠️ ข้อมูลเก็บแยกกันตามเบราว์เซอร์/เครื่อง เพราะเป็น `localStorage` — ถ้าเปิดจากมือถือกับคอม ข้อมูลจะไม่ sync กันเอง (ดูหัวข้อ "พัฒนาต่อ" ด้านล่าง)

## ทุกครั้งที่แก้โค้ดในอนาคต
1. แก้ไฟล์ในโฟลเดอร์ repo
2. เปิด GitHub Desktop → จะเห็นการเปลี่ยนแปลง → ใส่ข้อความ commit → `Commit to main`
3. กด `Push origin`
4. รอ 1-2 นาที เว็บที่ลิงก์ GitHub Pages จะอัปเดตอัตโนมัติ

## แนวทางพัฒนาต่อ (ในอนาคต)
- **สรุปรายเดือน**: กราฟ/ตารางสรุปรายจ่ายแยกตามหมวดหมู่ รายเดือน
- **Sync ข้ามอุปกรณ์**: ถ้าอยากให้มือถือกับคอมเห็นข้อมูลเดียวกัน ต้องมีที่เก็บข้อมูลกลาง เช่น ใช้ Google Sheets เป็นฐานข้อมูลฟรีๆ, หรือ Firebase (มี free tier), หรือ export/import ไฟล์ JSON เอาเองไปมาก่อนก็ได้ระหว่างนี้
- **แจ้งเตือนจริงบนมือถือ**: เว็บทั่วไปแจ้งเตือนแบบ push ให้ตอนปิดแอปได้ยาก ถ้าอยากได้แจ้งเตือนจริงต้องทำเป็น PWA + Web Push (ทำได้ แต่ต้องมี server ช่วยส่ง)
- **แก้ไขรายการที่บันทึกผิด**: ตอนนี้ลบได้อย่างเดียว เพิ่มปุ่ม "แก้ไข" ได้ในเวอร์ชันถัดไป
- **Export ข้อมูล**: ปุ่ม export เป็น CSV/JSON ไว้สำรองข้อมูล กันเผลอล้าง cache เบราว์เซอร์แล้วข้อมูลหาย
